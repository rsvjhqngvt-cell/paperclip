이 스킬은 브랜드 템플릿 레이어 전용이다. 내용 작성 방식이나 메시지 구조는 판단하지 않는다.

## 추출 항목

- 슬라이드 크기와 비율
- 마스터와 레이아웃 구조
- 로고, 헤더, 푸터, 페이지 번호 좌표
- 제목, 본문, 표, 차트, 이미지 슬롯의 위치와 크기
- 색상 팔레트, 폰트, 줄 간격, 여백
- 안내선 또는 반복 정렬 좌표
- 이미지, 로고, 아이콘 자산

## 산출물 구조

- `brand-template-kit`: 전체 브랜드 규칙
- `layout-slot-schema`: 슬라이드 유형별 배치 슬롯
- `fixed-elements`: 로고와 고정 요소 좌표
- `asset-inventory`: 재사용 가능한 자산 목록
- `fit-constraints`: 텍스트/표/차트가 넘칠 때의 조정 기준

## 원칙

- 기준 PPT는 최종 외형을 맞추기 위한 기준이며, 내용 논리를 결정하는 기준이 아니다.
- 스토리보드가 확정된 뒤에만 이 레이어를 적용한다.
- 한글 렌더링과 폰트 대체 여부를 반드시 확인한다.
