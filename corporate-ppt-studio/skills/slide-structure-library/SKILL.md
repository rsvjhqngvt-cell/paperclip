---

이 스킬은 내용 패턴 레이어 전용이다. 로고 위치, 안내선, 좌표, 색상, 폰트는 결정하지 않는다.

## 분석 대상

- 장표의 목적과 독자 질문
- 제목과 핵심 메시지 작성 방식
- 근거, 표, 차트, 이미지의 역할
- 장표 간 논리 흐름
- 전문용어 설명 방식
- 임원 보고용 요약 문장 패턴

## 산출물 구조

- `pattern_name`: 장표 패턴명
- `when_to_use`: 어떤 상황에서 쓰는지
- `message_formula`: 제목과 핵심 메시지 작성 공식
- `evidence_blocks`: 필요한 근거 블록
- `visual_candidates`: 표, 차트, 다이어그램 후보
- `term_note_policy`: 전문용어 설명 위치와 분량
- `recommended_density`: 한 슬라이드에 담을 정보량

## 금지 사항

- 기준 PPT의 좌표에 맞추기 위해 내용을 먼저 축소하지 않는다.
- 로고, 안내선, 색상, 폰트 규칙을 이 라이브러리에 섞지 않는다.
- 특정 PPT 한 장의 디자인을 모든 내용 구조의 기준으로 삼지 않는다.
