이 프로젝트는 브랜드 템플릿 레이어 전용입니다. 내용 작성 방식이나 스토리보드 구조는 결정하지 않습니다.

사용자가 최종 산출물의 기준으로 지정한 PPT에서 외형 규칙만 추출해 `brand-template-kit`과 `layout-slot-schema`로 저장합니다.
