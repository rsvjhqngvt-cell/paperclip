추출된 기준 PPT 정보를 새 PPT 생성에 쓸 수 있는 브랜드 템플릿 키트로 정리한다.

필수 포함 항목:
- 슬라이드 유형별 슬롯 좌표
- 로고와 고정 요소 위치
- 색상 팔레트와 폰트 규칙
- 표/차트/이미지 배치 가능 영역
- 텍스트가 넘칠 때의 조정 기준
- 한글 폰트 대체 여부와 렌더링 확인 방법

주의:
- 이미 확정된 스토리보드를 임의로 바꾸지 않는다.
- 내용 축약이 필요하면 `overflow-or-fit-issues`로 별도 요청한다.
