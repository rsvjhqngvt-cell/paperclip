최종 기준 PPT에서 브랜드 템플릿 레이어를 추출한다.

작업 범위:
- 슬라이드 크기와 비율
- 마스터와 레이아웃 구조
- 로고, 헤더, 푸터, 페이지 번호 좌표
- 제목, 본문, 표, 차트, 이미지 슬롯 좌표
- 안내선 또는 반복 정렬 좌표
- 색상, 폰트, 줄 간격, 여백
- 재사용 가능한 이미지, 로고, 아이콘 자산

제외 범위:
- 내용 작성 방식
- 스토리보드 구조
- 메시지 표현 방식

필수 산출물:
- brand-template-kit
- layout-slot-schema
- fixed-elements
- asset-inventory
