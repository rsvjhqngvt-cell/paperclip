여러 PPT 또는 기존 산출물을 분석해 내용 작성 방식과 장표 구조를 추출한다.

작업 범위:
- 슬라이드별 목적과 독자 질문
- 제목, 핵심 메시지, 근거, 시사점 작성 방식
- 표, 차트, 이미지가 쓰이는 이유
- 전문용어와 약어 설명 방식
- 장표 간 흐름과 반복되는 스토리라인

제외 범위:
- 로고 위치
- 안내선과 좌표
- 색상, 폰트, 마스터
- 최종 기준 PPT의 디자인 규칙

필수 산출물:
- content-pattern-library
- storytelling-rules
- term-explanation-rules
