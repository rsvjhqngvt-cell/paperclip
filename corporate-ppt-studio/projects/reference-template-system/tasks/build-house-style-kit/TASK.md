분석된 PPT들의 내용 구성 방식을 재사용 가능한 라이브러리로 정리한다.

필수 포함 항목:
- 장표 패턴명
- 사용 조건
- 제목 작성 공식
- 핵심 메시지 구조
- 필요한 근거 블록
- 표/차트 후보
- 전문용어 설명 방식
- 권장 정보 밀도

주의:
- 이 산출물에는 안내선, 로고, 색상, 폰트, 좌표 규칙을 넣지 않는다.
- 최종 브랜드 적용은 `Brand Template System`에서 별도로 처리한다.
