이 프로젝트는 내용 패턴 레이어 전용입니다. 기준 PPT의 안내선, 로고, 좌표, 색상, 폰트는 분석하지 않습니다.

여러 PPT 또는 기존 산출물이 들어오면 장표별 목적, 메시지 흐름, 제목 작성 방식, 표/차트 활용 방식, 전문용어 설명 방식을 추출해 `content-pattern-library`로 저장합니다.
