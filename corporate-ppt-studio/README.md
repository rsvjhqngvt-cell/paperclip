# 회사 PPT 제작 스튜디오

자료의 내용 구성 방식과 최종 PPT의 브랜드 양식을 분리해서 운영하는 Paperclip 회사 패키지입니다.

## 핵심 원칙

1. 내용 작성 방식은 여러 PPT에서 학습한다.
2. 장표 구조는 내용 패턴 라이브러리로 관리한다.
3. 안내선, 로고, 색상, 폰트, 마스터, 고정 좌표는 기준 PPT에서 별도 추출한다.
4. 새 자료를 만들 때는 먼저 내용 스토리보드를 확정하고, 이후 브랜드 템플릿 레이어를 적용한다.
5. 최종 QA는 내용 품질, 브랜드 적용, 한국어 렌더링을 분리해서 확인한다.

## 기본 흐름

1. 여러 PPT 또는 기존 산출물 분석
2. 내용 패턴 라이브러리 구축
3. 최종 기준 PPT 분석
4. 브랜드 템플릿 키트 구축
5. 원자료 수집 및 구조화
6. 스토리보드 작성
7. 브랜드 템플릿 적용 및 PPTX 생성
8. 렌더링 QA 및 한글 깨짐 확인
