# PMI 체크리스트

## Day 1-7 체크리스트 (클로징 직후)

- [ ] 임직원 전체 미팅 개최 (인수 배경·비전·고용 보장 발표)
- [ ] 대표이사 변경 등기 신청
- [ ] 법인 인감 및 인감증명서 수령
- [ ] 은행 계좌 명의 이전 착수 (주거래 은행 방문)
- [ ] 법인카드 권한 조정 (기존 오너 카드 회수, 신규 발급)
- [ ] 공인인증서(금융·정부24 등) 명의 이전
- [ ] 회계법인/세무법인 선임 계약
- [ ] 핵심 임직원 (영업팀장, 기술팀장) 개별 면담 실시
- [ ] Retention offer 전달 (상여금 또는 주식 옵션 제안)
- [ ] IT 시스템 관리자 계정 인수인계
- [ ] 기존 오너 퇴직 임직원 접근권한 즉시 회수

## Day 8-30 체크리스트

- [ ] Vendor별 계약 이전 공문 발송 (신 대표이사 명의)
- [ ] Vendor 담당 AM과 첫 미팅 (관계 유지·파트너 등급 확인)
- [ ] 기존 고객사 Top 20 방문 또는 연락 (인수 공지·영업 담당 소개)
- [ ] 리셀러 채널 파트너 공지 발송 (거래 조건 유지 확인)
- [ ] 영업 파이프라인 전수 인수인계 (진행 중 딜 목록·예상 클로징)
- [ ] 미수금·선수금 현황 파악
- [ ] 계류 소송 또는 클레임 현황 법무법인 보고
- [ ] 전 오너 퇴직금 정산 및 계약서 서명
- [ ] 정관 변경 (필요 시)
- [ ] 사업자등록증 명의 변경

## Day 30-90 체크리스트

- [ ] 월간 경영 보고 체계 구축 (손익·현금흐름·파이프라인)
- [ ] 회계법인과 첫 월간 결산 보고 수령
- [ ] Vendor 쿼터 리뷰 미팅 참석 (파트너 등급 유지 확인)
- [ ] 추가 vendor 라인 후보 검토 (현 gap 대비)
- [ ] 비용 구조 분석 — 불필요 고정비 3개 이상 식별
- [ ] 성과 평가 체계 초안 작성 (HR)
- [ ] 인센티브 구조 정비 (영업 커미션 기준 명확화)
- [ ] 주요 계약 만기 캘린더 작성 (vendor·고객·리스)

## Day 90-180 체크리스트

- [ ] 신규 segment 또는 vertical 진출 전략 보고서 작성
- [ ] 채널 파트너 활성화 프로그램 설계 (리셀러 인센티브)
- [ ] 마케팅 활동 1회 이상 (웨비나 또는 사례 발표)
- [ ] 추가 vendor 인증 취득 계획 수립
- [ ] 다음 M&A 타겟 리서치 재개 (포트폴리오 확장)
- [ ] 6개월 경영 성과 보고 (Board에 제출)
