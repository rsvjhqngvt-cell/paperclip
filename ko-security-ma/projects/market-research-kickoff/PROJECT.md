IT 보안 솔루션 기업 및 총판/리셀러 인수를 위한 최초 시장 분석 프로젝트입니다.
EDR, NDR, ZTNA, IAM, DLP, OT보안, 클라우드보안, WAF, AI보안 9개 segment를
분석해 초기 집중 영역을 선정합니다. 1회성 프로젝트.

즉시 시작 가설은 다음 3개 세그먼트입니다:
- ZTNA / SASE
- IAM / PAM
- 클라우드 보안 (CNAPP / CSPM / CWPP)

OT / ICS 보안은 watchlist로 유지하되, 초기 플랫폼 인수 이전에는 보수적으로 접근합니다.
AI Security / Agent Security / Guardrails는 전략 세그먼트로 별도 추적하되, 직접 경영권 인수보다는 채널·운영 역량 확보 관점에서 우선 접근합니다.
